# Roadmap / ideas

- Verify on more devices (Adreno vs Mali), measure real canvas performance.
- Touch layer: gesture mapping for pan/zoom/select, bigger toolbar targets.
- Release APK signed with a stable key and an in-app update check.
- Pre-seed KiCad config (graphics backend, UI scale) once the setting names are confirmed.
- Longer term: a touch-first native editor reading KiCad's S-expression files, or a wxQt-based native port
  (see dsa-t/kicad-android for a proof of concept).
